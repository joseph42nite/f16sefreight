Scope: `app/`, `routes/`, `config/`, `database/`, Docker files and `python/`. Front end excluded.

Method: read-through by six parallel reviewers plus a mechanical duplicate-function scan. PHP and Docker were not
available on the machine, so **no lint, no tests and no code were run** (the Python reviewer did run the pure
extraction functions on sample inputs). Items already in `GAPS.md` were skipped.

Marks: **[V]** = re-checked against the source by the lead after the reviewer reported it. Unmarked = reviewer
read the code and reported it as confirmed, not re-checked. **[P]** = plausible, depends on timing, data or
deployment that could not be tested.

## 7. Python OCR service

`extract_awb_new.py` is ~740 lines of code plus an 8,400-line airport table; no function is defined twice. The
newer model path is well tested; the older coordinate path has no tests and returns confidently wrong values.

- `resolve_iata` (`:8425`) — KOCHI → KCZ (Japan), LONDON → YXU; COCHIN, TRIVANDRUM, CALICUT, KOLKATA unresolved; 46 valid codes resolve to a different airport. Also ~8,000 regex searches per call (10–16 ms) and 3.8 s import cost.
- `transform_awb_number` (`:9055`) **[V]** — "176 1234 5678" → "176-5678".
- Flight routing (`:8858`) — month names read as airports; 6E / G9 carriers not matched.
- Country detection (`geo_constants.py` + `:8569`) — "PH" phone label → Philippines; "INDIA GATE FOODS … DUBAI" → India.
- `extract_dimensions` (`:8923`) — phantom entries, decimals dropped.
- `ocr_server.py:79` **[V]** — sync extraction inside an async handler blocks the whole service; `:58,135` no upload size cap.
- `transform_piece_weight` (`:9018`) — a token "NAN" 500s the whole extract.
- Phone / pin / HS-code regexes over-match (`:8487`, `:8521`, `:8918`); `unstructured.py:180` reads "1,250.50" as 1.0.
- `model_extract.py:389` — timed-out calls keep their pool thread **[P]**; `:259` truncated JSON not retried; `:179` silent 12,000-char truncation.
- `boxes_config.json:43,31` — two box coordinates look like typos **[P]**.
- `geo_constants.py` — VIETNAM, COLOMBIA, BRAZIL, CHILE each defined twice; the later silently wins.
